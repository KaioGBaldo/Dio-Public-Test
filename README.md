# Desafio de Projeto: Git/GitHub - Bootcamp Eduzz

Este repositório foi desenvolvido como parte de um desafio prático proposto pelo Bootcamp da **Eduzz**. O objetivo central foi colocar em prática os conhecimentos adquiridos sobre controle de versão e colaboração utilizando Git e GitHub.

## 🎯 Objetivo do Desafio
O desafio consistiu em criar um ambiente de versionamento organizado, demonstrando a compreensão do ciclo de vida de um arquivo no Git e a estruturação de um repositório profissional no GitHub.

## 🛠️ Conceitos Praticados
Durante este projeto, foram aplicados os seguintes conceitos:

* **Configuração Inicial:** Configuração de ambiente, `user.name` e `user.email`.
* **Ciclo de Vida:** Comandos de `add`, `commit` e `push`.
* **Repositórios Remotos:** Vinculação de pastas locais com o GitHub.
* **Documentação:** Criação e formatação de arquivos `README.md` utilizando Markdown.
* **Organização:** Boas práticas na escrita de commits e estruturação de pastas.

## 🚀 Tecnologias Utilizadas
* **Git**: Para controle de versão local.
* **GitHub**: Para hospedagem e gerenciamento do código na nuvem.
* **Markdown**: Para documentação e formatação do projeto.
